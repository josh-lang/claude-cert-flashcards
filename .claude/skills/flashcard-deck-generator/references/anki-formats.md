# Anki Output Formats — exact syntax

Verified against the Anki manual (docs.ankiweb.net, 2026-08), genanki 0.13.1,
and AnkiConnect API v6 (add-on 2055492159, canonical repo:
git.sr.ht/~foosoft/anki-connect — the GitHub repo is archived).

## Text import (TSV) — Anki 2.1.54+

Plain UTF-8 text (no BOM). `#key:value` file headers, one per line at the top
(older clients ignore them). Supported keys:

| Key | Values | Behaviour |
| --- | --- | --- |
| `#separator:` | `Comma` `Semicolon` `Tab` `Space` `Pipe` `Colon` or literal | field separator (put this header first) |
| `#html:` | `true`/`false` | treat field content as HTML |
| `#tags:` | space-separated tags | added to every imported note |
| `#columns:` | names joined by the separator | column names/count |
| `#notetype:` | name or id | preset notetype (must exist) |
| `#deck:` | name or id | preset deck (`::` hierarchy ok) |
| `#notetype column:` | `1`,`2`,… | per-row notetype → mixed types in one file |
| `#deck column:` | `1`,`2`,… | per-row deck |
| `#tags column:` | `1`,`2`,… | per-row tags |
| `#guid column:` | `1`,`2`,… | per-row GUID for update-in-place |

With a `#notetype column`, fields map implicitly: the first *regular* column →
first field of each row's notetype, and so on.

### This skill's canonical layouts (emitted by `build_tsv.py`)

Single notetype:

```
#separator:tab
#html:true
#deck:Flashcards::Example
#tags:source::example
#notetype:Basic
#columns:guid Front Back tags
#guid column:1
#tags column:4
<sha1-hex> What is X? X is Y. topic::demo
```

Mixed notetypes (Basic + Cloze in one file):

```
#separator:tab
#html:true
#deck:Flashcards::Example
#tags:source::example
#columns:guid notetype field1 field2 tags
#guid column:1
#notetype column:2
#tags column:5
<sha1-hex> Basic What is X? X is Y. topic::demo
<sha1-hex> Cloze {{c1::Rome}} is the capital of {{c2::Italy}}. Source: notes.md topic::demo
```

### Escaping and multi-line fields

- Fields containing the separator, quotes, or newlines are wrapped in double
  quotes; a literal `"` inside is doubled (`""`). `csv` QUOTE_MINIMAL semantics.
- **Newlines inside fields: use `<br>`** (requires `#html:true`). Quoted real
  newlines are legal but break clozes that span lines — this skill always
  converts `\n` → `<br>`.
- Not using HTML? Replace `<` `>` `&` with `&lt;` `&gt;` `&amp;`. This skill
  always uses `#html:true`, so escape those characters when they are *literal*.

### GUIDs, duplicates, updating

- GUID match → the existing note is found: with **Existing notes: Update**
  (default) its fields update **in place, preserving scheduling**. A provided
  GUID that already exists never creates a duplicate (the "Duplicate" option is
  ignored for rows with non-empty GUIDs).
- Without GUIDs, the **first field** is the identity key (same notetype).
- This skill's guid = `sha1("source|slug|ordinal")` hex — stable across runs;
  `--fresh` salts it to force new notes.
- Known quirk (ankitects/anki#4205): some files' `#notetype:` header can be
  ignored while other headers are honored — **always check the import preview**;
  the mixed layout's per-row notetype column sidesteps this.

### Media

Plain TSV **cannot bundle media**. Fields may reference
`<img src="name.jpg">` / `[sound:name.mp3]`, but the files must already be in
`collection.media` (flat, no subdirectories). Otherwise use `.apkg` or
AnkiConnect `storeMediaFile`.

## Cloze syntax

- `{{c1::text}}`; hint: `{{c1::text::hint}}`; `{{c1::…}} {{c2::…}}` → separate
  cards; reusing the same number hides both on one card. Nesting ok (2.1.56+).
  Deletions need not fall on word boundaries (`C{{c1::anberra}}`).
- The Cloze notetype has fields **`Text`** and **`Back Extra`** (shown on the
  answer side). It cannot be created from a regular notetype and cannot gain
  extra card templates.

## Notetype names (exact strings)

`Basic` (Front/Back) · `Basic (and reversed card)` (2 cards) ·
`Basic (optional reversed card)` · `Basic (type in the answer)` · `Cloze` ·
`Image Occlusion` (23.10+; not generated by this skill).

## genanki (.apkg) — `build_apkg.py` internals

- Stable baked IDs: `BASIC_MODEL_ID = 1893207705`,
  `BASIC_REV_MODEL_ID = 1921666369` (generated once at skill build). Models are
  named `Basic (FlashcardGen)` / `Basic and reversed (FlashcardGen)` so they
  never collide with Anki's built-ins. Cloze uses `genanki.CLOZE_MODEL`
  (id 1550428389, name `Cloze (genanki)`, fields `Text`/`Back Extra` —
  genanki ≥0.13.0 required for the two-field model).
- `deck_id` derives from the deck name:
  `(1<<30) + sha1(name)[:8] % (1<<30)` — same name → same id every run,
  different decks never share an id.
- Note GUIDs are set explicitly to the same sha1 hex as the TSV emitter; a
  re-imported `.apkg` with a matching GUID **updates** the existing note
  (models must have the same fields).
- Media: `Package.media_files` = list of file paths; Anki stores by
  **basename** — fields must reference basenames only; basenames must be
  unique.
- Field data is HTML; escape literal `<` `>` `&`.

## AnkiConnect API v6 — cheat sheet (`ankiconnect.py` internals)

HTTP POST to `http://127.0.0.1:8765`, envelope
`{"action": …, "version": 6, "params": {…}}` (optionally `"key"` when the
add-on's `apiKey` config is set). Response is exactly
`{"result": …, "error": null|"msg"}`. **Always send `"version": 6`** — older
versions return a bare result. Anki must be running with add-on 2055492159.

| Action | Params → Result |
| --- | --- |
| `requestPermission` | none → `{permission: "granted"\|"denied", …}` (call first) |
| `version` | none → API version int |
| `deckNames` / `createDeck` | `{deck: "A::B"}` → names[] / new deck id |
| `modelNames` / `modelFieldNames` | `{modelName}` → names[] |
| `canAddNotes` | `{notes:[…]}` → bool[] |
| `addNotes` | `{notes:[…]}` → (id\|null)[] |
| `storeMediaFile` | `{filename, data\|path\|url}` (precedence data→path→url) → stored name; prefix `_` to protect unused files from purge |
| `sync` | none → null (desktop app syncs with its stored AnkiWeb login) |
| `getProfiles` / `loadProfile` | none → names[] / `{name}` → bool |
| `multi` | `{actions:[…]}` → results[] |

Note object for `addNote(s)`:

```json
{"deckName": "D", "modelName": "Basic",
 "fields": {"Front": "…", "Back": "…"},
 "tags": ["topic::x"],
 "options": {"allowDuplicate": false, "duplicateScope": "deck",
   "duplicateScopeOptions": {"deckName": "D", "checkChildren": false, "checkAllModels": false}},
 "picture": [{"path": "/abs/img.jpg", "filename": "img.jpg", "fields": ["Back"]}]}
```

`duplicateScope: "deck"` checks only the target deck. AnkiConnect **cannot set
GUIDs** — push is insert-with-duplicate-skip; `updateNoteFields` exists for
targeted edits by note id (don't have the note open in the Browse editor).
`push` maps this skill's two canonical field values **positionally** onto
`modelFieldNames(modelName)`, tolerating renamed/localized fields.
